# اپلیکیشن ترک عادت — نسخه ۲ (Habit Breaker v2)

اپلیکیشن حرفه‌ای و انگیزشی ترک سیگار و خودارضایی با طراحی مدرن Jetpack Compose، سیستم پاکسازی تصاعدی لکه‌های بدن شخصیت، معماری تمیز MVVM و ذخیره‌سازی کاملاً آفلاین Room.

---

## 🌟 قابلیت‌های کلیدی برنامه

- 🇮🇷 **رابط کاربری کاملاً فارسی و راست‌چین (RTL)** با استفاده از Material 3 و رنگ‌بندی جذاب شب و روز.
- 🎯 **انتخاب عادت هدف:** پشتیبانی اختصاصی از ترک سیگار (🚬) و ترک خودارضایی با متون و فرمول‌های انگیزشی متناسب.
- 👤 **شخصیت پویا و زنده (مرد و زن):** نمایش وضعیت روحی و جسمی کاربر در ۵ مرحله تدریجی (غمگین و خسته → امیدوار → خوشحال → جهش و شادی → رقص و انرژی کامل).
- 🧬 **سیستم هوشمند لکه‌های بدن:** نمایش سابقه عادت به صورت لکه‌های بصری کنترل‌شده روی بدن شخصیت و پاکسازی تصاعدی آنها با افزایش روزهای پاکی (روز اول ۱ واحد، روز دوم ۲ واحد، روز سوم ۴ واحد و...).
- 📊 **ثبت وضعیت روزانه هوشمند:**
  - دکمه «امروز موفق بودم» همراه با انیمیشن جشن و افزایش تصاعدی پیشرفت.
  - بخش «لغزش و روز سخت» بدون هرگونه سرزنش یا بار منفی، همراه با ثبت محرک‌ها (استرس، تنهایی، خستگی و...).
- 🧘 **بخش آرامش و تمرین تنفس فوری (SOS / موج‌سواری بر وسوسه):** کمک به کاربر در لحظات هجوم وسوسه.
- 🏆 **سیستم دستاوردها و مدال‌های پاکی (Achievements):** قفل‌گشایی نشان‌های افتخار در بازه‌های مختلف (۱ روز، ۳ روز، ۱ هفته، ۱۰ روز، ۲۱ روز، ۱ ماه و...).
- 🔒 **۱۰۰٪ آفلاین و محلی:** بدون نیاز به اینترنت، لاگین یا کلیدهای API. تمامی داده‌ها در پایگاه داده امن Room ذخیره می‌شوند.

## 🚀 راهنمای بیلد خودکار در GitHub Actions (بدون نیاز به Android Studio)

این پروژه طوری پیکربندی شده است که با فشردن دکمه Push در گیت‌هاب، به‌صورت کاملاً خودکار فایل APK نسخه Release و امضاشده (Signed APK) آماده انتشار در کافه‌بازار و مایکت را تولید و به عنوان Artifact تحویل می‌دهد.

### ۱. ساخت فایل Keystore (کلید امضای برنامه)

در ترمینال سیستم خود دستور زیر را اجرا کنید:

```bash
keytool -genkey -v -keystore release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
```

در حین اجرا، یک رمز عبور انتخاب کنید و اطلاعات خواسته شده (نام، سازمان و...) را وارد کنید. در پایان یک فایل به نام `release.jks` ایجاد می‌شود.

---

### ۲. تبدیل فایل Keystore به Base64

برای انتقال ایمن کلید به GitHub Secrets، فایل `release.jks` را با یکی از دستورات زیر به متن Base64 تبدیل کنید:

#### در لینوکس / مک:
```bash
base64 -w 0 release.jks > keystore_base64.txt
```

#### در ویندوز (PowerShell):
```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("release.jks")) | Out-File -Encoding ASCII keystore_base64.txt
```

محتوای فایل `keystore_base64.txt` را کپی کنید.

---

### ۳. تنظیم GitHub Secrets

در مخزن گیت‌هاب خود به مسیر زیر بروید:
**Settings** > **Secrets and variables** > **Actions** > **New repository secret**

این ۴ متغیر مخفی را دقیقاً با همین نام‌ها تعریف کنید:

| نام Secret | مقدار |
| :--- | :--- |
| `KEYSTORE_BASE64` | متن کامل رشته Base64 تولید شده از مرحله قبل |
| `KEYSTORE_PASSWORD` | رمز عبوری که در زمان ساخت Keystore وارد کردید |
| `KEY_ALIAS` | نام مستعار کلید (مثلاً `upload`) |
| `KEY_PASSWORD` | رمز عبور کلید (معمولاً همان پسورد Keystore) |

---

### ⚠️ اهمیت حیاتی نگهداری فایل Keystore

> **هشدار بسیار مهم:**
> فایل `release.jks` اصلی و رمزهای آن را همیشه در مکانی امن نگهداری کنید و از آن نسخه پشتیبان (Backup) داشته باشید. برای انتشار هرگونه آپدیت و نسخه‌های بعدی این اپلیکیشن در مارکت‌ها (کافه‌بازار، گوگل‌پلی، مایکت)، حتماً باید از همین فایل Keystore و مشخصات یکسان استفاده شود؛ در غیر این صورت کاربران قادر به آپدیت برنامه نخواهند بود!

---

### ۴. دریافت APK خروجی

پس از Push کردن پروژه در گیت‌هاب:
1. به تب **Actions** در ریپازیتوری خود بروید.
2. روی آخرین اجرای ورک‌فلو **Build Android Release APK** کلیک کنید.
3. در پایین صفحه و در بخش **Artifacts**، فایل فشرده `app-release-apk` حاوی فایل APK امضا شده نهایی را دانلود کنید.

## 🛠️ ساختار معماری فنی

- **زبان:** Kotlin
- **طراحی رابط کاربری:** Jetpack Compose + Material 3 + AnimatedContent
- **پایگاه داده:** Room Database (KSP)
- **پترن معماری:** MVVM (Model-View-ViewModel) + Single Source of Truth + Kotlin Coroutines & StateFlow
- **جهت‌بندی:** پشتیبانی بومی RTL (LayoutDirection.Rtl)
